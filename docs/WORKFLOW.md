# 制作流程全记录 · How this film was made

《一个有月亮的晚上》是一部张爱玲手绘传记短片（4:45，配赵雷《程艾影》）。
**全部画面由代码逐笔绘制：没有摄影机，没有 AI 生图，也没有照片素材。**
整部片由 Claude Opus 5.5 作为导演 agent，统筹 8 个并行子 agent 完成，人类只提出需求、给出反馈。

---

## 0. 输入

用户只提供了三样东西：

| 输入 | 内容 |
|---|---|
| 需求 | 「对张爱玲所有的作品以及生平……手绘版本……专业级别，有文学情怀，配上她的名句」 |
| 参考片 | 一部 B站 上的 AI 生成短片：2.39:1 宽银幕，暗调，用文字堆成风景，中英双语旁白，片尾有制作署名 |
| 音乐 | 赵雷《程艾影》 |

## 1. 导演阶段（film-director）

1. **读参考片**：用 ffmpeg 每 3 秒抽一帧拼成总览图，总结出它的视觉语法。
2. **分析歌曲**（skill `song-analysis`）：
   - 117.45 BPM，共 544 个节拍；
   - 能量曲线：前奏 −40 dB → 主歌 −27 dB → 副歌 −17 dB → 高潮 −11 dB，247.8 秒处骤停；
   - whisper 识别歌词的时间点，再按官方歌词逐句校正。
3. **找到歌与人的关联**：歌里的「程艾影」普遍被认为是「张爱玲」的谐音，常德路是她住过的常德公寓所在地，「从上海到武汉」对应胡兰成 1944 年去武汉，「尘埃里花」呼应她的「低到尘埃里」。
4. **定叙事者**：《金锁记》里的那个月亮——「我是一个月亮。她写过我很多次。」月亮也是全片唯一的暖光。
5. **写旁白**（skill `narration-script`）：49 条双语字幕卡在乐句上，名句逐字核对出处，事实整理成 SCRIPT.md。
6. **写引擎**（skill `pen-engine`）：
   - `pen.ts`：带笔压的墨带、手抖、每秒 8 次的线条重绘、逐笔显现、排线、水彩；
   - `ground.ts`：夜纸、旧纸、月亮；
   - `type.ts`：双语字幕、竖排手写、歌词栏；
   - `film.ts`：场景调度、墨晕/烧纸/闪白转场、胶片颗粒；
   - `tools/stills.mjs`：只打包一次，就能批量截取任意时间点的帧。
7. **写 BRIEF.md**：所有子 agent 共读的唯一一份说明。

## 2. 并行制作（8 个子 agent）

| agent | 类型 | 负责 |
|---|---|---|
| H1 | figure-artist | 青年张爱玲 5 个造型，以及 1954 年那张经典照的黑白相纸模式 |
| H2 | figure-artist | 童年、17 岁被幽禁、1955 年船舷、晚年侧脸、晚年伏案 |
| AG | scene-artist | A 段开场、标题 ＋ G 段太平洋、月落、片尾字幕 |
| B | scene-artist | 1920 麦根路、1924 母亲远行、烟榻、1937 幽禁、1938 出逃 |
| C | scene-artist | 1939 香港、华美的袍、1941 香港沦陷、《倾城之恋》、1943–44 成名 |
| D | scene-artist | 常德公寓、门缝里的字条、尘埃里开花、婚书、地图、温州、诀别信、1952 离沪 |
| E | scene-artist | 克利夫兰总统号、纽约与胡适「悲风」、赖雅、洛杉矶、雨窗、晚年 |
| F | scene-artist | 红白玫瑰、《半生缘》、《更衣记》、对照记、黑白照、1995 |

几条约定：
- 导演先公开人物库的接口（先放占位实现），各段 agent 可以立刻按这个接口排人物的位置和大小。
- 每个 agent 只改自己的文件。
- 每个 agent 至少走 3 轮「渲静帧 → 看图 → 修改」（skill `stills-review`），交稿时附上总览图。

## 3. 审片与用户反馈

导演亲自看每一张总览图（不只看 agent 的文字报告），再用 SendMessage 给对应 agent 发修改清单。

**第一轮用户反馈：**
- 「多加名句」「写年少成名」「晚年远渡重洋」「细节多一些」
  - 新增 8 句写进画面的原文；
  - 成名段从 7 秒扩到 10 秒，并新增一句旁白；
  - 轮船一场做成重头戏；
  - 所有段落加细节。
- 「相框里放那张最有名的黑白照」：给人物库加 mono 模式，模拟银盐相纸，眼皮半垂、下巴上扬。

**第二轮用户反馈，是一次风格转向：**
- 「这样的场景（文字之海）可以多一些，前面的动画少一些，做成参考片那样」
  - 新增公共模块 `textmatter.ts`（skill `text-matter`）：人物、城市、月光、雨、海都由她的文字组成，并从文字里浮现；
  - 6 段全部改用这种画法，钢笔线只保留为点缀。
- 「不需要描红」：去掉稿纸红格。
- 「完全就是这一种黄色」：整屏黄纸的镜头改成夜色加灯光。
- 「售完这个词不用」：旁白改为「一时洛阳纸贵」。
- 「这个花好丑」：改成由题字里的字聚成的玉兰。
- 「长度也是」：片长改为 4:45，音乐在结尾的器乐段淡出。
- 「我要发 B站」：降低胶片颗粒、生成 CC 字幕、写投稿文案、做封面。

## 4. 渲染与交付（render-engineer）

- 按 7 段分别渲染 1080P，分段边界精确到帧，拼接后共 6852 帧，8 个 Chrome 并行约 25 分钟。
- 开场的钢笔书写声由程序合成：从场景代码里导出 87 段书写时间，用带通噪声加 25–45 Hz 的颗粒调制模拟笔尖。
- 响度用线性增益调到 −14.0 LUFS，真峰值 −2.0 dBTP。编码为 H.264 High@4.1，峰值码率封顶 20 Mbps。
- 封面、CC 字幕和投稿说明，见 skill `bilibili-publish`。

## 5. 踩过的坑

| 现象 | 原因 | 解决 |
|---|---|---|
| 片头第 1 秒爆音 | 单遍 loudnorm 用的是动态模式 | 先测响度，再用线性增益 |
| 「下载之后点不开」 | 23 Mbps 码率标成 Level 4.0，硬件解码器拒绝播放 | 改为 Level 4.1，VBV 封顶 20M，文件名用英文 |
| 后台编码随会话一起中断 | 会话结束时后台进程被杀 | 每次都核对输出文件的时长 |
| 某个 agent 的半成品让大家都无法打包 | 共用一个打包入口 | stills 加 `--mod`，只注册自己的模块 |
| 静帧很慢（2–5 秒/帧） | 每张静帧都冷启动、重建缓存 | 实际成片渲染时平均约 1.7 秒/帧/worker |

## 6. 规模

- 约 **340 万 token**，其中子 agent 约 323 万；
- **14,510 行代码**；
- **8 个子 agent**，2 轮用户反馈，每个 agent 3–9 轮自审；
- 6852 帧，1920×804，24fps。
