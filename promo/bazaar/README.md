# 米麦集市 MIME BAZAAR — 每个人都可以开一家店（60 s）

> 开一家店，卖你的灵感。 　|　 密码保护资产 · 数学生长价值 　|　 mimuseai.com

一支 60 秒、1920×1080、30 fps 的宣传片，讲清米麦的交易模式：**每个人都能开店**，上传自己的素材（脸、声音、经验、作品、文化资产、灵感）并定价；**别人来逛、来买**；钱先由平台托管，**店主点头才交付**，然后自动结算。

画面全部由代码绘制（Canvas 2D），配乐和音效全部用 numpy 合成。没有 AI 生图，没有第三方素材。

## 制作

在 `promo/` 目录下：

```bash
python3 -I bazaar/tools/music.py bazaar.wav
node tools/render.mjs --page bazaar/index.html --stills 2,7,12,20,31,40,50,57 --out sheet.jpg
node tools/render.mjs --page bazaar/index.html --video mime_bazaar.mp4 --audio bazaar.wav --workers 4
```

- `bazaar.js` 是本片的时间线。它在 `../mishu/film.js` 之后加载，复用那里的绘图库（人像 `frontFace`、商品图标 `plateIcon`、金币、logo、字体与 `boot()`），再定义自己的 `render(t)`。
- `tools/music.py`：配乐和音效，包括木琴式琶音、打字声、剪彩声、货物落架声、金币声、收银声。
