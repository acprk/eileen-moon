# 米麦 MIME TECH · 密数科技 — 商业宣传片（60 s）

> 密码保护资产 · 数学生长价值 　|　 mimuseai.com

一支 60 秒、1920×1080、30 fps 的商业宣传片，内容依据 [acprk/mishu-platform](https://github.com/acprk/mishu-platform)。
全片只讲两件事：**数据传上来以后，你自己掌控**；**每用一次，你就有一次收益**。

画面全部由代码绘制（Canvas 2D），没有用 AI 生图，也没有第三方素材。

|---|---|---|

## 商业版（`commercial.html` / `commercial.js`）

与 `../bazaar/commercial.js` 用同一套商业语言（参考 [`../REFERENCES.md`](../REFERENCES.md) 第 1、2、5、8 条，共用 `../lib/cmkit.js`）：近黑底配单一金色点缀；画面上没有界面外壳，文案逐字浮现；一个形状从不硬切；闭式弹簧曲线；运动模糊。

| 时间 | 段落 | 画面 |
|---|---|---|
| 0–8 s | 为什么 | 金色细框的「展品」（灵感博物馆）：你的脸 / 你的声音 / 你的虚拟形象 / 你的灵感 → 都是你的资产 |
| 8–14 s | 痛点 | 可一旦上传，就被复制、被滥用，你却无从收回 |
| 14–34 s | 解决 | 上传 → 本地识别 → 加密成金色密文、仅你可解锁 → 你的密钥（只在你的设备上）→ 上架（使用权 · 按次、每次需你同意）→ 星河影业的请求，你点「同意」→ 受控生成、用后即焚 → 授权列表里滑动并一键撤销 → 所有权从未离开你 → 账本记录每一次使用 → 金币 |
| 34–46 s | 你得到什么 | 结算高潮：蓄力 → 爆发 → 「+¥1,950」→ 金币飞进「你的收益」；之后订单继续入账 |
| 46–54 s | 数学生长价值 | 一条金色价值曲线带着账本节点生长，「密码保护资产，数学生长价值。」 |
| 54–60 s | 落版 | 光线扫出 logo、米麦 · MIME TECH、口号、mimuseai.com |

```bash

node tools/render.mjs --page mishu/commercial.html --video mime_promo_commercial.mp4 --audio ms.wav --workers 4 --blur 4
```

## 产品说明书 v7（`v7.html` / `v7.js`）· 密数科学研究院 出品

参照用户提供的三支苹果短片（Creator Studio、Apple Watch Series 12、Apple Card）重做：

- **背景全部是纯色色场**，每段换一种颜色（靛蓝、墨绿、白、橙、米白、紫、金、午夜蓝、黑、绿），没有网格、粒子、地台和幻灯片外框，避免审美疲劳。
- 每个画面只有一个大主体和一行字；字幕随旁白逐词浮现（Watch 的做法）。
- 主体的形状长成下一段的色场（圆形扩散），只有动词段在节拍上硬切。
- 工艺镜头：针尖在白卡上刻出米麦标志和名字，卡片翻面露出「使用权 ¥2,000 / 次」（Apple Card）。
- 动词段一词一拍、一词一种动效（Creator Studio）；巨大的开关在绿色光晕里（Watch 电池）。
- 收尾在黑底：logo、「密数科学研究院，出品」，配乐此时停下。

| 时间 | 段落 | 色场 | 画面 |
|---|---|---|---|
| 0–3.4 s | 出品 | 黑 | 金色细线、「密数科学研究院 出品」 |
| 3.4–5.9 s | 片名 | 黑 | 银色「米麦」扫光、产品说明书 |
| 5.9–12.9 s | 七种资产 | 每秒一色 | 一张脸 / 一段声音 / 一个虚拟形象 / 一段经验 / 一件文化数字资产 / 一幅作品 / 一个灵感 |
| 12.9–15 s | 都是你的资产 | 黑 | 七色圆点 + 金色「资产」 |
| 15–21 s | 第 1 步 上传 | 午夜蓝 | 正脸肖像被扫描，自上而下化成金色密文，上锁「仅你可解锁」 |
| 21–27 s | 第 2 步 上架 | 白 | 针尖刻卡，卡片 3D 翻面：使用权 ¥2,000 / 次，所有权永远归你 |

| 48–51 s | 动词 | 黑 | 上传。确权。上架。授权。收回。收益。 |
| 51.7–57 s | 由你决定 · 口号 | 黑 | 一切，由你决定。密码保护资产，数学生长价值。 |
| 57–60 s | 落版 | 黑 | logo、密数科学研究院 出品、密数科技（北京）有限公司 · mimuseai.com |

**配音**：中文女声旁白，用离线 TTS 合成（sherpa-onnx + Kokoro multi-lang v1.0，Apache-2.0，模型不入库）。

- 每个短语单独合成，再按固定停顿拼接，避免逗号处多出语气词；
- 短语时间写入 `v7_vo.js`，画面字幕按它逐词出现；
- 音色是按语音识别回读的字错率选出来的（`zf_xiaoxiao`）。

**配乐**（`tools/music_v7.py`）：按参考片实测的特征来做。

- 节奏 120 BPM，能量集中在超低频；
- 每个元素一个音效；
- 揭示之前留一拍静音（12.6 s、47.5 s），片尾卡不配乐；
- 旁白出现时音乐压低约 7 dB；
- 母带约 −15.5 LUFS（参考片为 −15～−16 LUFS），响度范围约 7 LU。

```bash
python3 -I mishu/tools/vo_v7.py <kokoro-multi-lang-v1_0 目录> vo7 47 0.95     # 旁白 + v7_vo.js
python3 -I mishu/tools/music_v7.py v7_mix.wav vo7                            # 配乐 + 音效 + 旁白；不给 vo7 则只出配乐
node tools/render.mjs --page mishu/v7.html --video mime_promo_v7.mp4 --audio v7_mix.wav --workers 4 --blur 4
```

## 制作

在 `promo/` 目录下：

```bash
python3 -I mishu/tools/logo_alpha.py <logo.webp> mishu/assets/logo.png   # 保留 logo 原有的透明通道
python3 -I mishu/tools/music.py music.wav                                # 原创配乐，numpy 合成，120 BPM，卡点对齐画面
node tools/render.mjs --page mishu/index.html --stills 3,8,15,24,33,42,50,56 --out sheet.jpg   # 联系表，一定要看图
node tools/render.mjs --page mishu/index.html --video mime_promo.mp4 --audio music.wav --workers 4
```

- `film.js`：整片时间线，`render(t)` 是关于时间 t（秒）的纯函数。`museum()` 画灵感博物馆，`frontFace()` 画正脸肖像，`hook()` 画色块快切，`stage1…5` 画五章的卡片。
- 章节版式沿用第一版：编号 · 标题 · 英文 · 三行短句 · 标签 · 使用步骤 · 进度条。
- `../fonts/`：Noto Sans SC、Inter、JetBrains Mono（SIL OFL 1.1，取自 Fontsource）。
- 渲染出的视频和音频不入库（见仓库根目录 NOTICE.md）。
