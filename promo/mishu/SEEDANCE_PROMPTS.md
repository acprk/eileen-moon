## 4. 生成后：把原配乐和文字合回去

Seedance 生成的音频不会和原片卡点对齐，建议去掉生成的音频，换回原片配乐（原片音频已经在 `mime_part1_1080p.mp4` 里）：

```bash
ffmpeg -i seedance_part1.mp4 -i mime_part1_1080p.mp4 -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest part1_final.mp4
```

如果生成结果里的字有错，可以只把商品区域换成 Seedance 的画面，其余部分（文字、UI、logo）保留原片。这一步需要原片的分层素材，我可以导出带透明通道的文字/UI 层，告诉我即可。
